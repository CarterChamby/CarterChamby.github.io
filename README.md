# Bible Study Reference

A mobile-optimized quick-reference tool for Paul's Epistles and the Gospel of Matthew.

## What's included
- Chapter-by-chapter argument breakdowns for all 13 Pauline epistles
- All 28 chapters of Matthew with OT connection notes
- Full-text search across all chapters
- Expandable cards with key verses, arguments, and typological notes

## Live site
[CartherChamby.github.io](https://CartherChamby.github.io)

## Usage
Open on phone, add to home screen via Safari → Share → "Add to Home Screen" for app-like access.
